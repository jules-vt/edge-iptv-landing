## Indexation et serveur — vérifié le 2026-10-20

- `www` → apex : 301 ✓ · `/fr.html` → `/fr` : 301 ✓
- **Bug de déploiement trouvé** : le `rsync` de `deploy.yml` exclut `*.txt` sans `--delete-excluded`. Les fichiers exclus sont alors aussi protégés de la suppression. Conséquences :
  - **115 fichiers de janvier restent sur le serveur**, dont des dossiers d'anciennes URL (`/blog/how-to-install-iptv-iphone-ipad/`) qui répondent **403** au lieu de 404/301. Umami y a vu 3 visites depuis le 01/10.
  - **`robots.txt` est figé depuis le 12/01/2026** : celui que génère `app/robots.ts` n'a jamais été déployé (sans gravité ici, les deux autorisent tout).
  - Correctif proposé : `--delete-excluded` + `--include='robots.txt'`, plus une 301 nginx `/blog/how-to-install-iptv-iphone-ipad` → `/how-to-install-iptv-iphone-ipad`.
